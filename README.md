# UniRes VOT Management System

This repository contains a **Next.js** application that implements the **Pengurusan VOT UniRes** system, backed by **Supabase** and integrated with **Google Gemini** for AI‑generated report summaries.

## Features
- CRUD for VOT, Tabung Amanah, and Akaun Amanah.
- Monthly auto‑payment logic (records expenses month‑by‑month).
- PDF report generation matching the Excel layout (HTML template in `lib/reportHtml.js`).
- AI summary generation using Google Gemini.
- Single‑user **SUPER_ADMIN** role (JWT based auth).
- Ready for deployment on **Vercel**.

## Setup & Deployment
1. **Create a Supabase project**
   - Enable the Table API and get the `SUPABASE_URL`, `SUPABASE_ANON_KEY`, and `SUPABASE_SERVICE_ROLE_KEY`.
   - Run the SQL schema (see `supabase_schema.sql` in the repo) to create tables:
     - `users`, `vots`, `tabung_amanah`, `akaun_amanah`, `expenses`.
   - Insert a SUPER_ADMIN user (or use the `/api/admin/clear` endpoint to create one).

2. **Configure environment variables** (Vercel dashboard → Settings → Environment Variables):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `JWT_SECRET` – a strong random string.
   - `GEMINI_API_KEY` – your Google Gemini API key.

3. **Deploy to Vercel**
   - Connect the GitHub repository (or push the code as a zip to Vercel).
   - Vercel will run `npm install` and `npm run build`.
   - After deployment, you will receive a live URL.

4. **Usage**
   - `POST /api/auth/login` with admin credentials → receives a JWT.
   - Include `Authorization: Bearer <token>` in all subsequent requests.
   - Use the VOT endpoints to add records, trigger auto‑payment, and generate PDF reports.
   - Call `GET /api/ai/summary` to obtain an AI‑generated summary of the latest report.
